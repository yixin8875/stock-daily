## 1. 产品概述

### 1.1 产品定位

股票日记本系统是一款面向个人股票投资者的交易记录与复盘工具。通过结构化的"今日总结"和"明日计划"功能，帮助投资者养成良好的交易习惯，提升投资决策质量。

### 1.2 产品愿景

**让每一次交易都有迹可循，让每一次复盘都有价值。**

### 1.3 目标用户

| 用户类型 | 特征描述 | 核心需求 |
|---------|---------|---------|
| 新手投资者 | 入市1年以内，缺乏系统性交易方法 | 建立交易纪律，记录学习过程 |
| 进阶投资者 | 有一定经验，希望提升胜率 | 复盘分析，优化交易策略 |
| 成熟投资者 | 有稳定交易系统，追求精细化管理 | 数据统计，策略验证 |

### 1.4 核心价值主张

- **结构化记录**: 标准化的日记模板，降低记录门槛
- **交易复盘**: 通过历史回顾发现交易模式和问题
- **情绪管理**: 记录交易心理，避免情绪化决策
- **计划执行**: 明日计划功能促进交易纪律性

## 2. 用户场景与用户故事

### 2.1 核心使用场景

**场景一：收盘后复盘（主场景）**
- 时间：每个交易日15:00-21:00
- 行为：用户打开系统，记录今日交易情况，分析得失，制定明日计划
- 频率：每个交易日1次

**场景二：盘前准备**
- 时间：每个交易日09:00前
- 行为：查看昨日制定的明日计划，确认今日操作策略
- 频率：每个交易日1次

**场景三：周末复盘**
- 时间：周末
- 行为：回顾本周所有交易记录，查看统计数据，总结经验教训
- 频率：每周1次

**场景四：策略验证**
- 时间：不定期
- 行为：通过历史记录和统计数据，验证某个交易策略的有效性
- 频率：每月1-2次

## 3. 功能需求详细说明

### 3.1 今日总结功能 [P0]

#### 3.1.1 日期记录
- 自动填充当前日期，支持手动修改
- 日期格式：YYYY-MM-DD
- 非交易日（周末、节假日）给予提示但不阻止记录

#### 3.1.2 大盘点评
```
字段说明：
- 大盘走势：单选（大涨/小涨/平盘/小跌/大跌）
- 成交量：单选（放量/缩量/平量）
- 点评内容：文本域，最大500字
- 板块热点：多选标签，支持自定义
```

#### 3.1.3 交易记录
```
每条交易记录包含：
- 股票代码：必填，6位数字，自动补全股票名称
- 交易方向：必填，买入/卖出
- 成交价格：必填，数字，最多2位小数
- 成交数量：必填，整数，100的倍数
- 成交金额：自动计算
- 交易原因：选填，文本，最大200字
- 策略标签：选填，关联策略库
```

#### 3.1.4 盈亏情况
```
字段说明：
- 今日盈亏金额：数字，支持正负
- 今日盈亏比例：数字，百分比格式
- 持仓市值：数字
- 可用资金：数字
- 总资产：自动计算（持仓市值+可用资金）
```

#### 3.1.5 操作反思
```
字段说明：
- 做对了什么：文本域，最大500字
- 做错了什么：文本域，最大500字
- 改进计划：文本域，最大500字
- 反思标签：多选（追涨/杀跌/止损/止盈/仓位/择时等）
```

#### 3.1.6 情绪记录 [P1]
```
字段说明：
- 开盘前情绪：单选（兴奋/平静/焦虑/恐惧/贪婪）
- 盘中情绪：单选（同上）
- 收盘后情绪：单选（同上）
- 情绪备注：文本，最大200字
```

#### 3.1.7 学习笔记 [P1]
```
字段说明：
- 笔记内容：富文本，支持图片
- 知识分类：单选（技术分析/基本面/交易心理/市场规律/其他）
- 关联股票：多选，关联股票代码
- 信息来源：文本，最大100字
```

### 3.2 明日计划功能 [P0]

#### 3.2.1 关注股票
```
每条关注记录包含：
- 股票代码：必填，6位数字
- 股票名称：自动填充
- 关注原因：选填，文本，最大200字
- 关注级别：单选（重点关注/一般关注/观察）
- 技术位置：选填（突破/回调/底部/顶部）
```

#### 3.2.2 买入计划
```
每条买入计划包含：
- 股票代码：必填
- 计划买入价：必填，数字
- 计划仓位：必填，百分比（如10%、20%）
- 买入理由：选填，文本，最大200字
- 触发条件：选填，文本（如"放量突破20日线"）
```

#### 3.2.3 卖出计划
```
每条卖出计划包含：
- 股票代码：必填
- 目标卖出价：必填，数字
- 卖出比例：必填，百分比
- 卖出理由：选填，文本
- 触发条件：选填，文本
```

#### 3.2.4 止损设置 [P1]
```
每条止损记录包含：
- 股票代码：必填
- 止损价位：必填，数字
- 止损原因：选填，文本
- 当前持仓成本：显示字段
- 止损幅度：自动计算百分比
```

#### 3.2.5 风险提示 [P1]
```
字段说明：
- 风险类型：多选（系统风险/个股风险/仓位风险/情绪风险）
- 风险描述：文本域，最大500字
- 应对措施：文本域，最大300字
```

### 3.3 历史回顾功能 [P0/P1]

#### 3.3.1 日历视图 [P0]
- 以月历形式展示，有记录的日期高亮显示
- 点击日期可查看当日完整记录
- 支持按月切换
- 显示每日盈亏颜色标识（红涨绿跌）

#### 3.3.2 列表视图 [P0]
- 按时间倒序展示日记列表
- 每条显示：日期、大盘走势、盈亏金额、交易笔数
- 支持无限滚动加载
- 支持日期范围筛选

#### 3.3.3 股票维度视图 [P1]
- 按股票代码聚合所有相关记录
- 显示该股票的所有交易记录
- 计算该股票的累计盈亏
- 展示操作时间线

### 3.4 统计分析功能 [P1]

#### 3.4.1 交易统计
```
统计指标：
- 总交易次数：买入+卖出次数
- 盈利次数/亏损次数
- 胜率：盈利次数/总平仓次数
- 盈亏比：平均盈利/平均亏损
- 最大单笔盈利/亏损
- 连续盈利/亏损次数
```

#### 3.4.2 收益统计
```
统计指标：
- 累计收益金额
- 累计收益率
- 月度收益曲线图
- 周度收益柱状图
- 最大回撤
```

#### 3.4.3 行为统计
```
统计指标：
- 平均持仓天数
- 交易频率（日/周/月）
- 常用策略分布
- 情绪与盈亏关联分析
```

### 3.5 标签系统 [P1]

#### 3.5.1 系统预设标签
```
策略标签：趋势跟踪、均值回归、突破、抄底、追涨、波段、短线、中线
板块标签：科技、消费、医药、金融、周期、新能源、半导体等
反思标签：追涨、杀跌、止损、止盈、仓位过重、频繁交易等
```

#### 3.5.2 自定义标签
- 用户可创建自定义标签
- 标签支持颜色设置
- 标签可编辑、删除
- 标签使用次数统计

### 3.6 搜索功能 [P2]

#### 3.6.1 全文搜索
- 搜索范围：大盘点评、交易原因、操作反思、学习笔记
- 支持关键词高亮
- 支持搜索结果排序（时间/相关度）

#### 3.6.2 高级筛选
- 按日期范围筛选
- 按股票代码筛选
- 按标签筛选
- 按盈亏状态筛选
- 多条件组合筛选

## 7. MVP范围定义

### 7.1 MVP功能清单

**必须包含 (Must Have)**:
- [ ] 用户注册/登录
- [ ] 今日总结：日期、大盘点评、交易记录、盈亏情况、操作反思
- [ ] 明日计划：关注股票、买入计划、卖出计划
- [ ] 历史回顾：日历视图、列表视图
- [ ] 数据持久化存储

**应该包含 (Should Have)**:
- [ ] 情绪记录
- [ ] 学习笔记
- [ ] 止损设置
- [ ] 基础统计（胜率、累计收益）

**可以延后 (Could Have)**:
- [ ] 标签系统
- [ ] 高级统计分析
- [ ] 全文搜索
- [ ] 数据导出

**不包含 (Won't Have)**:
- [ ] 实时行情接入
- [ ] 社交分享功能
- [ ] AI智能分析
- [ ] 移动端App

### 7.2 MVP验收标准

1. 用户可以完成完整的日记记录流程
2. 用户可以查看历史记录
3. 数据不丢失，支持基本的数据安全
4. 页面加载时间 < 3秒
5. 支持主流浏览器

### 7.3 MVP开发周期

| 阶段 | 时间 | 交付物 |
|-----|-----|-------|
| 设计阶段 | 1周 | UI设计稿、数据库设计 |
| 开发阶段 | 3周 | 前后端代码 |
| 测试阶段 | 1周 | 测试报告、Bug修复 |
| 上线准备 | 0.5周 | 部署、文档 |
| **总计** | **5.5周** | MVP版本上线 |
